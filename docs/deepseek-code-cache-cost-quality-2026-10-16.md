# 第三项：真实代码交付与随机交叉测试

2026-10-16（北京时间）。本轮通过桌面暂存的官方 Host 向真实 DeepSeek Flash 发送请求，要求模型读取并修改临时项目文件，再运行独立隐藏测试。测试对象是四个生成的软件任务，不是外部真实仓库，也不是通用工程能力排名。

后续已补路径白名单、失败代码独立修复，以及第四项权限／恢复负例，详见[问题修复与第四项检查](permissions-recovery-2026-10-16.md)。本文 v1/v2 原始条件和分数保留。

## 实验设计

四题为 CSV 解析、半开区间并集、依赖图并行波次、整数指数退避。每题有固定规格、缺陷初始代码、公开测试与至少八个隐藏断言。调用前检查参考解全部通过，初始代码不能通过公开测试；将规格及测试哈希记入收据。隐藏测试和参考解不写入模型工作区。

基础 `task-00` 与全开 `task-0f` 各执行每题两轮，共 16 次交付、8 对配对比较。先随机打乱题目与轮次，再随机分配四对基础先行、四对全开先行；随机种子和完整顺序在发请求前落盘。同一临时工作区路径，每次重新写入相同初始文件、创建新会话并确认能力快照。第一条请求不假定为冷缓存，配对也不能消除全部缓存延续影响。

模型相同、thinking 关闭、每次响应最多 2,048 tokens。全开组保留更大的可见工具目录，但两组均按文件任务指令操作；不能用本实验声称使用联网、子代理或 Fusion 的收益。请求流使用已验证的终止事件审计；完整 token 桶和实际响应型号决定官方价格估算，不从哈希推断缓存命中。[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

读取隔离的边界：测试器未把隐藏题或参考解投放进模型工作区，但本轮 Host 的文件工具守卫只按工具名限制，未设置读取路径白名单。官方文件沙箱主要限制写入，读取可以跨工作区。因此不能宣称模型工具层保证无法读取个人文件或评估目录，也不能把本轮称为防泄漏测试。收据保留了工具名，未逐次留存工具参数的路径审计；不能仅凭工具名证明全部读取均在指定目录内。评分子进程的 Node 文件权限限制与此不同，仍然生效。本轮结论限于实际交付和测试结果。

## 首次运行发现的问题（保留，不并入后续评分）

v1 收据：[失败运行](../dist/live-stage3-2026-10-15T15-54-45-003Z/receipt.json)、[完整提供方审计](../dist/live-stage3-2026-10-15T15-54-45-003Z/provider-audit.jsonl)、[统计摘要](../dist/live-stage3-2026-10-15T15-54-45-003Z/summary.json)。预排 16 次，只完成 6 次，随后 CSV 任务超时终止；该运行不具备完整交叉覆盖。

- 基础组第一次依赖图代码排除了自依赖边，导致自环没有抛错，未通过隐藏测试。这是实际实现缺陷，源码保留。
- 全开组一次重试任务虽然交付通过，却调用终端工具反复尝试验证，用了 17 次模型请求，违背了题面禁止终端的指令。
- 随后的基础组 CSV 任务又进入终端尝试，180 秒超时。不能只看已完成任务的通过率而漏掉它。
- 共发生 53 个提供方响应，均有完整终止计量。已完成六次试次只归属了其中 32 个；超时前的另外 21 个在完整审计中保留，报告列为未归属请求，仍计入该运行估算费用 **¥0.12518776**。不把它们从费用中删除，也不把中断试次算为成功。

这些结果说明，仅靠提示词“不要使用终端”不能稳定限制执行步骤。v2 在测试器中加入文件工具执行守卫、每题六次提供方请求硬限与明确的写完即结束指令；超时或预算耗尽先取消并等待结束，再记录失败。以上只改变隔离测试协议，没有改个人安装或生产插件。v1 与 v2 条件不同，分开报告。

## v2 隔离评估与验收口径

真实修改的 `solution.cjs` 复制到独立评估目录，在新的 Node 子进程中分别执行公开、隐藏测试。每个子进程限时五秒、内存 128 MB；只授予评估目录读取权限，不授予写入、子进程、工作线程、原生插件或 WASI 权限。模块白名单限制为断言和指定的测试／提交文件，禁用直接网络及 builtin/binding 入口。目录外读写、子进程、网络模块、fetch 和提前退出的负例已回归验证。这些是 Node 进程内限制，不是抵御恶意逃逸的操作系统沙箱。

一次交付成功须同时满足：轮次正常结束、源码确实改变、固定文件及文件清单未被改动、公开与隐藏测试全过。最终答复说“完成”不能替代实际代码测试。失败源码不由评估器修复，不向模型反馈隐藏测试。普通断言失败继续下一试次；计量缺失、取消无法结束或夹具被篡改则停止实验。

协议：[预先保存的实验契约](deepseek-code-experiment-contract.json)。

证据：[完整收据](../dist/live-stage3-2026-10-15T16-22-16-180Z/receipt.json)、[提供方审计](../dist/live-stage3-2026-10-15T16-22-16-180Z/provider-audit.jsonl)、[含配对差值的摘要](../dist/live-stage3-2026-10-15T16-22-16-180Z/summary.json)、[CSV 失败源码](../dist/live-stage3-2026-10-15T16-22-16-180Z/artifacts/csv-parser-r1-task-00/solution.cjs)。每次产物目录同时保留固定测试与评分器文件；完整退出码、错误堆栈及源码哈希在收据中。

本次全开组输入更长，但基础组有两次交付用了额外请求，因此本次费用总额反而略高。这说明工具数、输入长度、请求轮数和最终失败率必须一起看，不能用一次预填充 token 数代替实际交付成本。全部请求处于北京时间非高峰，响应型号均为 deepseek-flash；按官方人民币桶价格估算 v2 合计 **¥0.12365824**，连同首次中断的 v1 合计 **¥0.24884600**。这些均为文档价格估算，不是账户扣费账单。

八对比较中，七对同时通过，仅一对出现全开通过、基础失败；全开费用更低的为三对，更高的为五对，耗时更短和更长的各四对。只有四个独立题型且轮次重复，不能据此声称全开具有普遍质量优势；本轮也没有检验实际使用联网、子代理或 Fusion 的收益。更大的工具目录并未在这组数据中造成固定方向的成本差异。上一轮的自环漏检、终端循环，以及本轮的 CSV 空行错误，应作为后续工程任务验收的回归案例。
